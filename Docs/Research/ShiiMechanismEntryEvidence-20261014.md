# Sudajii independent gathering — feature-scoped implementation-entry evidence (2026-10-14)

**Scope:** only the technical ability to gather from an already spawned Environment-owned wood-primary `AMJ_Tree_Shii` without altering timber harvest. No new food quantity, resource ThingDef, regeneration duration, season, natural plant or release is decided here.

**Vanilla / MO / AMJ:** Environment `Defs/ThingDefs_Plants/AMJ_WildPlants.xml` gives Shii `TreeBase`, inherited wood-primary harvestedThingDef and `harvestYield=42`. Author-supplied MO 1.6 ZIP SHA-256 `6ed379d7c400db43b3af2a9a7fd6203f7f7e99ca1a670d36b0f73fd1adccc9e3` shows apple/lemon/mulberry fruit-primary regrowth (`harvestAfterGrowth=0.30`), with no fruit-tree timber-specific XML override. Native `JobDriver_PlantWork`/`JobDriver_PlantCut` reviewed in owner mechanism audit shares primary plant harvest and cut destroys tree; native loaded game NOT RUN. Replacing Shii primary wood with fruit or adding output to shared `PlantCollected` violates required dual action.

**VE:** Actual 1.6 VPE apple/peach/cherry XML and VPE More Plants almond/other trees are fruit-primary. VEF `DualCropExtension` uses a shared `PlantCollected` hook; cannot safely implement separately requested nut gathering and original tree chopping. No VE dependencies justified.

**Non-VE:** Actual `gguake/RWMod-Vivi` source on master, `Source/Gather/AI/JobDriver_Gather.cs` blob `d7a5d285a69afe7f6e31a638da503f07fb45d183`, `Source/Gather/Comps/CompRepeatGatherable.cs` blob `8f1d367e0b35df3b16d38efae4b2168f5068e0aa`, and `Mod/v1.6/Defs/Recipes/RecipeDefs_Gather.xml` blob `1b24a800785929f78cb0965efe96553a6b0f2599`: separate job targets a living Plant, produces unrelated product (tree propolis), and persists gather cooldown. It needs Biotech, Harmony, fantasy-race content and a mandatory gathering workbench, so use as prior art only; no copyrighted source/art copied. More Tree Products/Bunny Framework gives on-destroy secondary items, not living-tree gathering. VV New Harvest and VGP demonstrate fruit-primary regrowth (VV only public author statement; VGP log snippets); current raw VV tree XML is unavailable. Expanded Woodworking 2 supplies woodworking/compatibility, not a verified independent side-gather path; obsolete EW fork's `butcherProducts` timber-on-cut claim is not a current source test.

**Decision rationale:** Vanilla/VE/native shared-harvest extras would change original wood output; destruction-loot cannot preserve the tree; Vivi's stand-alone target-plant job establishes code-level feasibility but requiring a large fantasy race/Biotech dependency is disproportionate. A small AMJ-original **separate target-tree gather action with isolated save-persistent per-tree state** is justified as the narrowest mechanism. Keep the original Environment ThingDef primary yield, cutting, growth, native biome placement and optional MO WoodChain unchanged. Build no gathering bench. Reuse no upstream code or art. Other species are not approved by this decision.

**Limitations and boundaries:** Exact VV Trees source, EW2 current code and native 1.6 MO/AMJE timber/drop, four profiles, old saved trees and native job/comp are NOT RUN/NOT VERIFIED. These do not determine whether the independent mechanism is needed: source and behavior descriptions cover different actions. They DO block runtime acceptance and release. Any product-def, nut amount, cooldown duration, season, labor time, Japanese explanation, texture or Workshop release requires a separate owner specification/decision; this mechanism-only record does not authorize invented gameplay values. Native test contract F01-F14 remains NOT RUN.
