# 山野採集 — 12資源の採集方式・食用前処理・生息環境（2026-10-14）

**対象：** [採用確定12資源](ResourceAdoption-v1.md)。各資源の個別候補・所有・生態制約・未確定数値は [ResourceAcquisitionMatrix.json](ResourceAcquisitionMatrix.json) を対照表とする。この文書は既採用資源の**採集方式を分類する設計**であり、実ゲームで機能するDef/Jobを追加したわけではない。すべての実装方式は**候補**。採集量・作業時間・成熟度・更新周期・季節の閾値・栄養数値・出現重みを確定したことにしない。

## 1. 四系統と共有可能な処理

| 系統 | 採用資源ID | 振る舞いの要件 | 技術上の第一候補 | 共通化の単位 |
| --- | --- | --- | --- | --- |
| **木を残す種実採集** | WF-N01/N02/N03/N04 | 実・種子を採っても元の木を残す。伐採は従来の木材収穫だけ。採集済み状態の保存と再採集制限が必要 | **独立した樹木対象採集**。既存Shii木材主収穫を改変しない。新規Foraging樹木も木材と種実を分離。現在のShii専用C#は**無効な試作**であり移植の実証ではない | 共通の「樹木から別資源を採る」インターフェースを**将来**検討。4樹種を一律に固定数値・同一季節へしない |
| **若芽・葉柄採集** | WF-G01/G02/G03/G04 | 株・根茎を残す採取を優先。地上部採取と季節別再生を区別 | まず**Vanillaの植物収穫/再生**で株が生き残れるか実ソース・実機で検証する。不足時のみ独立した地上部採集Job | 地上部だけを採り、株を保全する共通概念。採れる部位・再生限界・生育期は種別 |
| **地下部の掘り取り** | WF-R01 | 採る対象は自然薯の**地下部**。地下部採掘を葉・茎の採取と同一視しない。採集後の個体と再生条件は別決定 | 自然物としてのPlantDefと通常の収穫/破壊で成立するか検証。成立する限り新C#を増やさない | 「地中の可食資源を掘り取る」独立カテゴリ。地表に常に食用可の芋アイテムがあるようにしない |
| **野生きのこの子実体採集** | WF-F01/F02/F03 | **木材でも宿主樹木でもなく子実体だけ**採る。菌根性と腐生性を同じ発生条件にしない。栽培なし | 自然に発生するForaging所有の菌類Thing/PlantをVanilla収穫できるか検証。**正しい宿主/基質に基づく発生条件**が不足する場合のみ補助C# | 収穫物としての子実体の共通インターフェース。ただし発生・寿命・宿主ロジックは別 |

**原則：** 先に既存のRimWorld XML/Jobを検証し、必要性が立証された部分だけC#を追加する。Vivi Race等の別Modは技術先例であり必須依存/コード流用ではない。既存Modに同じ食用種があるかは**採用対象および基本機能の実装順に無関係**。

## 1.1. 植栽の種別仕様（2026-10-14承認）

**採集対象＝植栽禁止ではない。** 自然発生・野生採集は12資源すべての基本機能とし、植栽は資源の性質に応じて独立判定する。正本の種別値は[ResourceAcquisitionMatrix.json](ResourceAcquisitionMatrix.json)の `plantingPolicy`。以下は**確定した設計上の植栽可否**であり、現行ソースに植え付けJobやThingDefが存在するとの主張ではない。

| 自然物（採用ID） | 植栽方針 | 条件・対象外 |
| --- | --- | --- |
| **スダジイ (WF-N01)** | **Environment既存仕様を維持（植林可能）** | `AMJ_Tree_Shii` はEnvironmentのWarmに自然分布。TreeBase由来の `sowTags=Ground`／`sowResearchPrerequisites=TreeSowing`／`mustBeWildToSow=true` と研究・地域制限を変更しない。Foragingは種実採集のみ重畳 |
| **クリ・クルミ・カヤ (WF-N02/N03/N04)** | **植林可能** | 新しい樹木はForaging所有。Vanilla既存の樹木栽培研究 `TreeSowing` 後に、当該樹種が自然分布する地域に限定して植林できるよう設計。非分布地域へ自由植栽できる仕様は認めない。木を残す種実採集と伐採木材は別 |
| **ワラビ・ゼンマイ (WF-G01/G02)** | **初期版は野生採集のみ** | 地下茎・シダの胞子繁殖を単純な農作物の種播きに置き換えない。移植や人工栽培は必要性を確認した将来の個別仕様とし、現時点で栽培メニューに表示しない |
| **フキ・ウド (WF-G03/G04)** | **植栽可能** | 野生採集を基本としつつ、既存の栽培ゾーンによる植え付けを許可。新しい種子アイテム、専用農業設備、軟白ウド栽培、工業的栽培システムは追加しない。採るのはフキ葉柄／ウド若芽・若茎 |
| **自然薯 (WF-R01)** | **初期版は野生掘り取りのみ** | 新規のヤマイモ栽培作物や農業システムは設けない。地下部の有限な掘り取りと再生を優先し、植え付けは別の作物設計に委ねる |
| **ヒラタケ・マツタケ・シイタケ (WF-F01/F02/F03)** | **植栽不可** | 野生の子実体だけを採集。栽培ゾーンへの播種、菌床・原木植菌・きのこ栽培研究/設備を追加しない。適正な宿主/朽木基質が必要 |

**現行のEnvironment正本：** [EnvironmentのRegional tree sowing contract](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Environment/blob/main/Docs/Design.md)§Regional tree sowing contract は、既存のShiiの樹木栽培研究/野生分布限定と、植林可能な樹木と高山ハイマツのような非植林木本との区別を規定している。新規のForaging食用樹木についても、その研究・地域制限に**矛盾しない独立Def**を作る。Environment本体や既存の植林候補を勝手に変更せず、Foragingを導入した場合のみ新規食用樹木が正しく候補に加わるようにする。

**実装したXMLの範囲（2026-10-14）：** [Foraging-owned abstract PlantDef templates](../Defs/ThingDefs_Plants/AMJWF_SowingBases.xml) は `TreeBase` の植林研究・地域制限の継承、`PlantBase`＋`Ground` でのフキ／ウド植栽、野生専用植物・菌類の `sowTags` なし、という**種別の継承ルールのみ**をソース化した。`Abstract=True` で `defName` を持たないため**ゲームの栽培メニューにはまだ現れない**。既存EnvironmentのスダジイPlantDefを編集していない。史実資源の出現重み／栄養／画像／植え付けJobは依然未実装。適用の技術判断は[Vanilla sowing decision](Research/NativeSowingEntryDecision.json)参照。

**実装優先度：** 可否と植栽可能条件の設計は決定したが、実際の植栽メニュー、研究ロック、地域制限、栽培Job、成長/種実採集の接続は**実ゲーム未検証**。クリ/クルミ/カヤ・フキ/ウドの具体的なXMLとソース必要性判定を次工程で行う。植栽を許すことは自動的な種子アイテム追加、無制限の食材産出、耕作/加工システムのMod所有移管を意味しない。

## 2. Environment実ソースに対する分布・宿主判定

2026-10-14現在のEnvironment mainを直接確認した（`Defs/BiomeDefs/AMJ_Biomes.xml` blob `f481efbec55ff28291d356fc735e4475920cd169`、`Defs/ThingDefs_Plants/AMJ_WildPlants.xml` blob `490f04c9b8b2aeb51b6ca63a0226be05a573b49b`）。

- `AMJ_WarmTemperateForest`: `AMJ_Tree_Shii=2.55` が既存分布。**スダジイをForagingで再配置・複製しない**。Warmには他の新規食用樹木・山菜・腐生菌類を**候補**として検討できるが、採用する実際の土地/温度/湿度と希少度は未確定。
- `AMJ_CoolTemperateForest`: `AMJ_Tree_Beech=1.8`、Vanilla `Plant_TreePine=0.35` が既存分布。**独自のアカマツ（`AMJ_Tree_Akamatsu`等）はこの植物ソースに存在しない**。`Plant_TreePine` をマツタケの宿主と**見なしてよいかは未決**。松が近くにいることを確認しないCool森林全域のマツタケ発生は採用しない。
- `AMJ_SubalpineForest` と `AMJ_AlpineZone`: 高地の亜高山・高山。**12資源を名称だけで高地に分散させない**。山菜など具体的に環境適合が確認できたものだけ追加検討する。ハイマツはアカマツの代替宿主とは断定しない。
- `TemperateSwamp`、`ColdBog` はEnvironmentが残すVanilla湿地BiomeDefs。沢辺の**フキ**など湿生食材の追加候補ではあるが、湿地Biomeの全域に同じ出現重みを入れない。Environment側の植生パッチを上書きしない。
- `wildPlantRegrowDays` はBiome側の植生回復設定であり、**採集した木の実・若芽・菌類が同じ日数で再び採れる証拠ではない**。個々の再採集状態を別に設計/テストする。
- 12資源の**新たな食用PlantDef、食材、画像、環境Biomeへの条件付き`wildPlants` PatchはForagingの所有**。Environmentに追加依頼しない。すでにEnvironmentが所有するスダジイ/ブナの本体Def/伐採/元の画像は不変。

**特に必要な生態試験：** (a) ワラビ・ウドは明るい林縁/山裾の再現ができるか、(b) 自然薯は地下部を形成しうる地表か、(c) クルミは谷/河畔環境が地形から判別できるか、(d) ヒラタケ・シイタケは**朽木/倒木**が実際に表現できるか、(e) マツタケは**生きた適格な松の根**が実際に近傍にあるか。林・バイオーム名や切り株の有無を、検証済みの実装ロジックと取り違えない。

## 3. 採ったものと食べられるものを分ける

| 食材候補 | 採集直後の扱い | 安全に食べられる状態の前提 |
| --- | --- | --- |
| **スダジイ・クリ・クルミ・カヤ** | 種実（クリのいが・クルミの外果皮/硬殻・カヤの殻等は可食本体と区別） | 種類ごとの殻外し・可食部位・加熱/加工の要否を定義。**生のまま食用にできると一律にしない** |
| **ワラビ** | 未処理の若芽 | **適切なアク抜き**が不可欠。一般的な「調理台で加熱」だけで毒性を完全除去できるものとはしない |
| **ゼンマイ** | 未処理の若芽 | 適切なアク抜き/加熱。乾燥保存工程はこのModの必須実装に混ぜない |
| **フキ** | 未処理の葉柄 | ピロリジジンアルカロイドへの**茹でこぼし・水さらし等の適切な前処理**を必要とする。フキノトウは未採用 |
| **ウド** | 野生の若芽/若茎 | 食用部位・処理方法を個別決定。歴史的食べ方が確定したと偽らない |
| **自然薯** | 掘り取った地下部 | 生食/加熱/下処理の可否を別決定。掘るだけで食事を無限に生産しない |
| **ヒラタケ・マツタケ・シイタケ** | 自然発生した子実体 | 確実に同定された食用菌を適切に調理。**野生シイタケを無加熱で安全な食事として扱わない** |

農水省はワラビ/フキの天然毒素とアク抜きを説明している（[山菜の食中毒防止](https://www.maff.go.jp/j/syouan/nouan/rinsanbutsu/natural_toxins.html)、[天然毒素・下処理講義資料](https://www.maff.go.jp/j/syouan/seisaku/seminar_jisseki/pdf/h28_siryo2.pdf)）。調理で天然毒が**完全に消える**とする説明はしない。**収穫素材・前処理済み中間素材・食事/料理**は区別し、最小の処理Recipeや既存調理工程の使い方は**別のゲームバランス設計**で決める。現段階で未処理素材の`ingestible`や栄養値を捏造しない。

## 4. 実装順と前提（機能優先、決まっていない数値は作らない）

1. **種実系の共通契約**：スダジイに対して「採集で木を残す／木材産出を変えない／再採集有限／既存木・旧セーブ対応」をC#/Def/実ゲームで検証する。その後クリ/クルミ/カヤに**既に採用されていることを理由に**同じ機構を適用可能か判断。木材主収穫Defを種実に改変しない。
2. **山菜系**：Vanilla収穫で個々の親株/根茎を残せるかを検証して、十分ならXMLで実装。不可なら種に必要な最小の若芽採集補助を検討する。ワラビ・ゼンマイ・フキの未処理→適正前処理は採集Jobとは別の食材処理契約として必須。
3. **自然薯**：地下部の収穫/枯死・再生を検討し、単純な植物収穫が規定した挙動を満たせば新Jobを追加しない。
4. **菌類系**：ヒラタケ/シイタケは自然の朽木基質、マツタケは適格な生松の根という**別の発生検証**を先に設け、菌類からの子実体採集は通常収穫を優先する。宿主や基質を実装できない場合、単なるBiome重みだけで架空の「どこでも自然発生」に逃がさない。
5. **受入検証**：既存木・食用新種・採集後資源・食品の状態遷移・環境分布・季節・旧セーブ・MO/CCTOとの独立プロファイルを個別に観測する。新しい食材の導入でEnvironment既存樹木の伐採木材/森林景観が変わらない。**1.6実ゲームではスダジイのF04～F06に相当する限定的な診断（Pawn Job、直後の再採集制限、予約競合、途中中断）が実行済み。F01～F14の正式な各項目は全件未受入であり、食材出力、保存・再読込、旧セーブ、MO/CCTO等は未検証**。

**作業状況：** この設計で全12資源の「採集形態／生息環境／処理」を候補分類した。画像制作・Def XML・採集Jobの本番接続・安全な料理Recipe・季節数値・ランタイム証拠はまだない。画像/食品/バランス/季節の承認を飛び越えない。
