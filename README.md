# Ancient & Medieval Japan - Wild Food Foraging / 中世日本 - 山野採集

> **2026-10-17 作者決定：本独立Mod計画はAMJ Environmentへ統合。** このリポジトリは過去の設計、12種の自然食料の採用根拠、仮XMLとRimWorld実機での限定的診断結果を残す**研究・開発履歴**。独立版の開発・配布は停止した。

**現在の実装所有者：** [AMJ Environment](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Environment)。本番仕様は[山野採集統合設計](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Environment/blob/main/Docs/ForagingIntegrationDesign-ja.md)とEnvironmentの[総合設計](https://github.com/sucRo-RimWorld/Ancient-Medieval-Japan-Environment/blob/main/Docs/Design.md)。山菜、種実・木の実、自然薯、野生菌類の12採用資源はそのまま継承する。

独立したWFFパッケージ、必須依存、Steam Workshop公開や本番の食材Defは作らない。旧資料内の独立Modと責務分担に関する記載は2026-10-17以降の現行所有仕様ではない。旧ソースに入っている試験用PlantDefと採集試作は正式なプレイ可能Modではない。
